O. Kafka를 사용하는 이유.
   - 두개 이상의 소프트웨어 레이어를 완전히 분리하여 독립적으로 동작할 수 있도록 함.
   -  MSA에서 micro service간 통신을 수행
   -  성능이 다른 service를 각자의 성능에 맞춰 scale out 하여 병목이 발생하지 않도록 하여 효과적으로 운영할 수 있음
   - 고성능 병렬처리가 가능하다.

O. OpenSearch/ElasticSearch를 사용하는 이유
   - 검색조건이 복잡 : DB를 쓸 경우 fullscan 발생
   - 대규모 로그 : 분산/병렬처리
   - 실시간 분석
   - 시계열 데이터
   - AI 검색 : RAG, Semantic Search, Vector Search
